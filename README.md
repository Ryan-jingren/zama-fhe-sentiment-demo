# Zama 文本情感分类同态加密演示

这是一个可以用来演示文本情感分类同态加密（FHE）的教学项目，大家可以参考说明自行部署。

- [中文部署说明与源码目录](zama-fhe-sentiment-demo/)
- [演示嵌入页面](zama-fhe-sentiment-demo/index.html)
- [官方演示及原始源码](https://huggingface.co/spaces/zama-fhe/encrypted_sentiment_analysis)

源码及模型快照由 GitHub Actions 自动导入，完成后位于 `zama-fhe-sentiment-demo/upstream/`，来源版本与校验信息见 `SOURCE_MANIFEST.json`。请在 Actions 中确认导入成功；若工作流失败，不能将本仓库视为完整源码副本。

原作者为 Zama；此仓库提供迁移、中文说明与嵌入页面，并非 Zama 官方维护项目。原演示在远端 Python 服务执行预处理和密钥操作，请使用虚构文本体验。
