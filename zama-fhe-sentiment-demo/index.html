文本情感分类 · 同态加密演示

体验在密文上分析文本情感的过程。以下为 Zama 官方 Hugging Face 演示，计算由该第三方服务运行。

  1. 生成密钥（Generate the keys）。
  2. 输入示例英文文本，再编码并加密。
  3. 运行密文计算（Run FHE execution）。
  4. 解密结果，查看负面、中性、正面的得分。

这是教学演示：输入文本、密钥生成和解密操作由远端 Python 演示服务处理，并非全部在你的浏览器中完成。请使用虚构文本，不要提交密码、个人隐私或商业机密。

如果嵌入内容无法加载，可在 Hugging Face 打开原演示 ↗。加载与可用性取决于第三方服务及当前网络。
